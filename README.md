# vstack OpenChamber Extension

OpenChamber visualization extension for vstack workflow engine. Provides a dashboard panel and full-screen page for viewing workflow state, deliveries, tasks, quality gates, reviews, releases, and evidence.

## Installation

### Via OpenChamber Extension Manager (Recommended)

1. Open OpenChamber Settings → Extensions
2. Click "Install from URL" or "Install from Git"
3. Enter: `https://github.com/<github-username>/vstack-openchamber.git`
4. Enable the extension

### Manual Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/<github-username>/vstack-openchamber.git
   ```
2. Build the extension:
   ```bash
   cd vstack-openchamber
   pnpm install
   pnpm build
   ```
3. In OpenChamber Settings → Extensions, click "Load Unpacked" and select the `panel/` directory

## Components

| Component | Type | Entry Point | Description |
|-----------|------|-------------|-------------|
| vstack Workflow | Panel | `panel/index.html` | Side panel showing workflow overview, deliveries, tasks |
| vstack Dashboard | Page | `panel/dashboard.html` | Full-screen dashboard with quality, reviews, releases, evidence |

## Features

- **Real-time polling**: Automatically refreshes every 3 seconds when visible
- **Schema validation**: Supports projection protocol v1 only
- **Files capability**: Requires `files` permission in OpenChamber to read `.vstack/` projections
- **Theme aware**: Adapts to OpenChamber's theme (light/dark)

## Projection Contract

This extension reads projections generated by the vstack OpenCode plugin (`@vstack/opencode`). The projections must conform to the vstack projection protocol v1 schemas defined in the umbrella repository.

Required projection files:
- `.vstack/manifest.json` - Project manifest
- `.vstack/state/index.json` - Dashboard index
- `.vstack/deliveries/*/delivery.json` - Delivery metadata
- `.vstack/deliveries/*/phases/*.json` - Phase runs
- `.vstack/deliveries/*/tasks/*.json` - Tasks
- `.vstack/deliveries/*/reviews/*.json` - Reviews
- `.vstack/deliveries/*/quality/*.json` - Quality gates
- `.vstack/deliveries/*/evidence/*.json` - Evidence
